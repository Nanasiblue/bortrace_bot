# bortrace_rebuild

競艇予測システムを旧コードから作り直すための新しい作業環境です。

## 旧データ

旧コードとデータは次を参照します。

`../bortrace_data`

データ量が大きいため、この新環境にはコピーせず参照で扱います。

## 初期構成

- `src/bortrace/`: 新実装
- `tests/`: テスト
- `scripts/`: 実行用スクリプト
- `docs/`: 調査メモ、設計メモ
- `work/`: 一時作業
- `outputs/`: 生成物

## 次の作業

1. 旧 parser / downloader / train / predict の責務を分離する
2. `B*.TXT` と `K*.TXT` の文字コード・形式を確認する
3. データ読み込みをテスト可能な小さい関数から作る
4. 学習・検証・予測を設定ファイル駆動にする
